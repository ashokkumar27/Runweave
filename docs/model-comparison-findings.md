The principal actionable findings are:

- **Local self-correction is possible with the present context.** Sol inferred the correct filename from the file list despite missing stderr text, executed `python report.py inputs.csv` exactly once successfully, and preserved `result.csv` as `total\n14\n`. Luna and Terra did not correct it. Sol subsequently repeated the original failure, including after seeing `exit_code: 0` and `changed: true`. Its recovery subgoal succeeded; accepted completion did not.
- **Completion behavior varies, but is still unreliable.** Sol's CSV completion respected `report_only` and honestly reported missing evidence; it triggered automatic syntax and byte checks. Terra/Sol direct completions also triggered checks, but both repeated completion after a rejected assessment. Sol explicitly claimed a byte check succeeded even though the projected assessment contained `accepted: false` and `remaining_gaps: ["evidence_required:output"]`. This is an observed decision failure independent of the missing expected bytes.
- **Expose the actual task specification before judging exact-format capability.** Projected checks include only `kind`, `argv`, and `path`; expected bytes are absent from both context and wire schema. CSV never supplies the required `valid_rows,rejected_rows,total` layout. All models produced correct cleaned rows eventually, but invented summary layouts. A stronger model cannot reliably infer an arbitrary inaccessible specification. The direct prompt's “containing 7+5” also permits a literal reading, while its hidden oracle requires `12\n`; this limits the arithmetic comparison.
- **Retain bounded action/result history and useful command diagnostics.** Context contains only `last_result`, not prior actions in the current root. `previous_turns` is empty throughout these fresh sessions. Command results expose exit code, output names, revision and change metadata, but no actual stdout/stderr text or the executed argv. The downloaded missing-file diagnostic exists publicly but is inaccessible through the projected semantic actions. This information loss is a plausible contributor to repeating the initial imperative; this single trial does not isolate its causal effect.
- **Make remaining root budget and completion state explicit, then re-evaluate separately.** `report_only` and automatic-check instructions are present, but explicit remaining root model attempts are absent. `available_child_budget` is a distinct child allocation, not a root-attempt counter. Seven raw work decisions were forced to blocked at the final-report boundary: Luna three, Terra two, Sol two. Do not score these as voluntary model refusals. The runtime correctly rejected unsupported success claims and preserved its checks; weakening the gates is not supported by these results.

These observations suggest future work on context/specification exposure and bounded history before relying on a model upgrade alone. No such changes were made in this campaign, and no extra calls were spent to test them. Exact per-call contexts, full instructions, wire schemas, raw decisions and corresponding runtime decisions are in the [audit](../var/acceptance/lightweight-model-comparison-v1/live-audit.json). Multiple responses contained more than one semantic output-tool call; the persisted runtime decision used the selected first action, so extra raw actions are not counted as executed. Reinspection, repeated writes and repeated failing commands consumed calls. The experiment used one root per exact model/fixture cell, reasoning `none`, output caps bug/CSV/recovery 1,024 and direct 768, and unchanged 16,000-token roots. Allocations were 5/6/6/3 per model. The original fixture bytes, prompts, instructions, tools, delegation policy, task checks and oracles were reused. Each cell had a fresh workspace/session through authenticated public APIs. Isolated API/worker processes used a unique database schema and task queue, an ephemeral loopback API port and the broker on 18091. Evidence was collected before removing the campaign schema. Production configuration/runtime, deployment 18000, unrelated 8000 and existing application volumes were untouched. Credentials were confined to worker memory and excluded from captures.

Scores are **exploratory single trials**, not statistical rankings or claims of inability at other budgets/settings. The bug AST oracle accepts a restricted expression language, so another correct implementation could fail it. Recovery requires the exact corrected command exactly once. Fake CSV actions already know expected bytes; their pass demonstrates mechanics, not inferability. Original fixtures and all these restrictions were preserved.
